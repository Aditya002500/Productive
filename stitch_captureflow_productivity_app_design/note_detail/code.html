Design System V2 Architecture

calendar_today Oct 24, 2023
update Updated 2 hours ago

The upcoming transition to Design System V2 necessitates a fundamental shift in how we handle state management within our shared components. The primary objective is to reduce re-renders and abstract the complex thematic logic away from the individual product teams.

During yesterday's sync, we aligned on moving towards a more robust token-based architecture. This means moving away from hardcoded hex values in the utility classes and relying strictly on the semantic tokens defined in the central repository.

Fig 1: Proposed Token Architecture Mapping

The immediate challenge will be retrofitting the existing `NavigationDrawer` and `BottomNavBar` components. These core navigational elements must flawlessly inherit the new `surface-container` layered elevation models without breaking the current responsive layouts on mobile devices.

Action Items Recap

  • Audit existing usage of `bg-white` and `bg-gray-100` across the main repository.
  • Draft the new `surface-elevation` utility plugin for Tailwind.
  • Schedule a review session with the frontend leads next Tuesday.
